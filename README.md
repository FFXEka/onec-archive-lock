# Блокировка изменений архивной базы

**1С:Предприятие · 1.13 · GPL-3.0-only**

[Скачать готовый файл](https://github.com/FFXEka/onec-archive-lock/releases/tag/v1.13) · [Исходники](src) · [Сообщить об ошибке](https://github.com/FFXEka/onec-archive-lock/issues)

Расширение для архивной копии базы 1С: перехватывает запись основных объектов и показывает пользователю, что база архивная. Помогает уменьшить риск случайных изменений при просмотре старых данных.

Исходное название на Инфостарте — «Полная блокировка изменения архивной базы». Здесь границы механизма описаны явно: **расширение не делает базу физически неизменяемой**.

## Как работает

- Подписки на `ПередЗаписью` запрещают запись документов, бизнес-процессов, справочной информации и наборов записей регистров.
- В переопределяемом модуле задаются разрешённые пользователи и исключения для служебных типов данных.
- При запуске выводится предупреждение об архивной базе.
- При наличии соответствующего интерфейса БСП вызывается запрет работы с внешними ресурсами.

## Установка

1. Сделайте резервную копию архивной базы и проверьте расширение на отдельной копии.
2. Загрузите CFE через управление расширениями конфигурации.
3. Проверьте применимость, необходимые для подписок настройки безопасности расширения и перезапустите сеанс.
4. Проверьте вход обычного пользователя, чтение данных, запрет записи нужных объектов и допустимые служебные операции.

Режим совместимости расширения — **8.3.14**, управляемое приложение. Это значение метаданных, а не подтверждение испытаний на каждой версии платформы начиная с 8.3.14.

## Границы блокировки

Служебные исключения включают рабочие места, варианты отчётов и другие данные, необходимые подсистемам. Полный список формируется в [переопределяемом модуле](src/CommonModules/ПолнаяБлокировкаСерверПереопределяемый/Ext/Module.bsl).

Пустые наборы записей регистров пропускаются обработчиком. Отдельных подписок на удаление объектов нет. Поэтому расширение не гарантирует запрет удаления или очистки данных всеми доступными способами. Администратор может отключить или удалить расширение. Права доступа и резервное копирование остаются самостоятельными мерами защиты.

## Что изменилось в 1.13

В исключения добавлен справочник `РабочиеМеста`: БПО может создавать его элемент при первом входе с нового компьютера. Ранее служебная запись могла прервать запуск сообщением о запрете изменений.

## Проверка

Штатный `CheckConfig` выполнен без ошибок в изолированной файловой базе и в тестовой ERP **2.5.16.115**. После загрузки CFE и обратной выгрузки все **19 из 19 файлов** совпали с исходниками. В статическом анализе остаются 26 диагностик существующего кода.

Вход с конкретного компьютера, на котором проявлялась проблема рабочего места, не воспроизводился. Его необходимо проверить после установки.

## Исходники и сборка

Каталог `src` содержит штатную XML/BSL-выгрузку. [Порядок сборки](docs/build.md). В релизе доступны готовый файл, ZIP с исходным русским именем файла, полный комплект исходников и контрольные суммы SHA-256.
