# Сборка CFE

Используйте отдельную пустую тестовую базу и конфигуратор 1С. Создайте расширение, откройте его конфигурацию и выполните загрузку конфигурации из файлов каталога `src`. Сохраните расширение в CFE.

После сборки проверьте применимость в копии нужной конфигурации и выполните штатную проверку конфигурации. Для контроля соответствия выгрузите собранное расширение обратно в файлы и сравните их с `src`.

Не загружайте XML расширения вместо основной конфигурации рабочей базы.
